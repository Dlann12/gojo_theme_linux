# cli-pet (Gojo 3D Terminal Overlay)

**Gojo Satoru 3D** beresolusi penuh (halus, anti-aliased, refleksi lantai + glow Hollow Purple) yang **otomatis hanya muncul saat jendela terminal aktif/fokus** di Pop!_OS COSMIC.

## Interaksi Mouse
- **Klik kiri** pada Gojo → sapa / elus
- **Double-click** → lempar orb untuk dikejar
- **Klik kanan** pada Gojo → menu cepat (Kasih Makan, Sapa/Elus, Main Bola, Tidur/Bangun, Ubah Mode Terminal/Semua Layar, Sembunyikan)

## Perintah CLI
```bash
pet show             # Munculkan Gojo
pet hide             # Sembunyikan sementara
pet feed             # Kasih makan (kikufuku)
pet pat              # Sapa / elus
pet play             # Main bola orb
pet sleep            # Tidur / bangun
pet scope terminal   # Hanya saat terminal aktif (default)
pet scope always     # Tampil di semua layar
pet status           # Lihat status
pet autostart off|on # Matikan / aktifkan auto-start
```
